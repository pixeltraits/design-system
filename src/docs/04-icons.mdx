# Icons

Le DS expose un composant `<ds-icon>` qui rend une icône Font Awesome
depuis un registre interne typé. Seuls les noms déclarés dans `DsIconName`
sont acceptés — pas de chaîne arbitraire.

## Usage

```ts
import { DsIcon } from '@codelyr/design-system';

@Component({
  selector: 'app-foo',
  imports: [DsIcon],
  template: `
    <ds-icon icon="check" />              <!-- taille md par défaut -->
    <ds-icon icon="moon" size="sm" />     <!-- 14 px -->
    <ds-icon icon="sun" size="lg" />      <!-- 24 px -->
  `,
})
export class Foo {}
```

## Couleur

L'icône hérite de la `color` du parent. La teinte se pilote en posant
`color: var(--ds-*)` sur l'élément qui englobe `<ds-icon>`. Pour un
override ponctuel sur un picto animé (`DsActionCard`), la custom prop
`--ds-action-card-icon-color` est exposée à l'host.

## Accessibilité

Une icône décorative — celle qui accompagne un libellé textuel — porte
`aria-hidden="true"` sur son élément englobant, pour éviter que le
lecteur d'écran lise le nom de l'icône en plus du texte. Le composant
n'ajoute pas l'attribut automatiquement parce que la sémantique dépend
du contexte d'usage.

```html
<span aria-hidden="true"><ds-icon icon="link" /></span> Lien externe
```

Une icône porteuse de sens — bouton icône-seule, par exemple — porte au
contraire un `aria-label` sur l'élément interactif.

```html
<button type="button" aria-label="Fermer">
  <ds-icon icon="xmark" />
</button>
```

## Ajouter une icône

Le registre vit dans
[`src/app/features/icon/presentation/icon-registry.ts`](?path=/story/components-icon--default).
L'ajout d'une nouvelle icône suit trois étapes.

1. Importer le glyphe depuis `@fortawesome/free-{solid,regular,brands}-svg-icons`.
2. L'ajouter à l'objet `DS_ICONS` avec un nom kebab-case stable.
3. Bumper le DS en minor — l'ajout étend l'API publique de `DsIconName`.

Toutes les icônes du registre sont chargées dans le bundle final. La
liste reste donc volontairement limitée aux pictos effectivement utilisés
par les applications consommatrices, pour ne pas alourdir le poids
téléchargé.
