# Design Tokens

La palette du DS passe entièrement par des CSS custom properties — préfixe
`--ds-*` pour les tokens propres, `--mat-sys-*` pour les tokens Material
M3. Aucune couleur n'est hardcodée dans les composants. La toolbar
« Thème » en haut de Storybook permet d'afficher les valeurs en jour ou
en nuit en temps réel.

---

## Surfaces

Trois niveaux d'élévation pour empiler les surfaces (page, card, rail).
Chaque token devient plus clair en mode jour, plus sombre en mode nuit.

<div className="ds-tokens-grid">
  {[
    ['--ds-bg', 'Fond global de la page'],
    ['--ds-bg2', 'Surface 1 — card, dialog, panneau'],
    ['--ds-bg3', 'Surface 2 — rail, footer, header'],
  ].map(([name, hint]) => (
    <div key={name} className="ds-tokens-swatch">
      <div className="ds-tokens-swatch__sample" style={{ background: `var(${name})` }} />
      <div className="ds-tokens-swatch__meta">
        <div className="ds-tokens-swatch__name">{name}</div>
        <div className="ds-tokens-swatch__hint">{hint}</div>
      </div>
    </div>
  ))}
</div>

## Bordures

Pour séparer deux surfaces ou marquer un état (hover, focus).

</div>

## Couleurs de marque

Le DS Codelyr s'articule autour d'un **violet** (primary) et d'un **orange**
(accent). Les `-l` (light) sont utilisés pour les textes sur fond sombre,
les `-dim` pour des fonds translucides.

<div className="ds-tokens-grid">
  {[
    ['--ds-primary', 'Violet principal — CTA, focus'],
    ['--ds-primary-l', 'Variante lighter — texte / icône sur sombre'],
    ['--ds-accent', 'Orange secondaire — accents, badges'],
    ['--ds-accent-dim', 'Accent translucide — fonds doux'],
  ].map(([name, hint]) => (
    <div key={name} className="ds-tokens-swatch">
      <div className="ds-tokens-swatch__sample" style={{ background: `var(${name})` }} />
      <div className="ds-tokens-swatch__meta">
        <div className="ds-tokens-swatch__name">{name}</div>
        <div className="ds-tokens-swatch__hint">{hint}</div>
      </div>
    </div>
  ))}
</div>

animation), ses tokens portent son préfixe. Ils basculent **jour/nuit**

## Tokens Material (interop M3)

Le DS s'appuie sur **`mat.theme()`** d'Angular Material 21 pour la base.
Les composants Material (`mat-dialog`, `mat-form-field`, `mat-button`…)
consomment naturellement ces tokens — en touchant les `--ds-*` ou en
posant `[data-theme]`, **les composants Material suivent**.

<table className="ds-tokens-table">
  <thead>
    <tr><th>Token</th><th>Rôle</th></tr>
  </thead>
  <tbody>
    <tr><td><code>--mat-sys-primary</code></td><td>Couleur primaire (Material)</td></tr>
    <tr><td><code>--mat-sys-on-primary</code></td><td>Texte sur primaire</td></tr>
    <tr><td><code>--mat-sys-surface</code></td><td>Surface niveau 0</td></tr>
    <tr><td><code>--mat-sys-surface-container</code></td><td>Surface niveau 2</td></tr>
    <tr><td><code>--mat-sys-outline</code></td><td>Bordure standard</td></tr>
    <tr><td><code>--mat-sys-outline-variant</code></td><td>Bordure secondaire</td></tr>
  </tbody>
</table>

La liste complète vit dans les mixins **`day-tokens()`** et **`night-tokens()`**
de `styles/_theme.scss`. Le mixin Material `mat.theme()` est ensuite appelé
dans `theme()` pour propager ces valeurs aux composants Material standards.
